# Lessons Learned

## Technical Lessons

* Syslog forwarding is an effective method for centralized log collection.
* Splunk provides powerful search capabilities for authentication monitoring.
* Authentication logs contain valuable security telemetry.

## Operational Lessons

* Centralized logging reduces investigation time.
* Detection logic should be documented and repeatable.
* Security monitoring requires validation through testing.

## Future Improvements

* Alerting
* Dashboards
* Threat Intelligence
* Correlation Searches
* Multi-Host Monitoring
