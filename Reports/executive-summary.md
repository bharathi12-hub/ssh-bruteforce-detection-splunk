# Executive Summary

## Project Name

SSH Brute-Force Attack Detection & Monitoring using Splunk

## Objective

Build a SIEM-based monitoring solution capable of collecting, analyzing, and investigating SSH authentication failures.

## Environment

* Splunk Enterprise
* Kali Linux
* Metasploitable 2
* Syslog

## Outcome

Successfully implemented centralized log collection and authentication event monitoring.

## Key Findings

* Authentication failures detected successfully.
* Invalid user login attempts identified.
* Security events indexed and searchable in Splunk.
* End-to-end monitoring pipeline validated.

## Business Value

Demonstrates practical SIEM deployment, log management, and SOC investigation workflows.
